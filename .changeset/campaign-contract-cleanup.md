Contract cleanup from the civfix-app campaign: unused value exports removed, the schemas' input limits and the helpers ui, web and mobile shared by copy exported once, the optional fields the backend and admin asked for, and a set of behaviour fixes. No endpoint is added or removed and no path, method, auth or csrf flag moves (the registry stays at 333 entries). See DECISIONS §58.

**Changed behaviour.**

- `AppError` sets `new.target.prototype`, so a subclass keeps its own prototype and `instanceof` the subclass holds without the subclass re-setting it. `MailSendError` no longer does.
- The typed client rejects a 2xx response other than 204 whose body is not JSON (an empty body included) with `AppError` `INTERNAL` ("Response body for HTTP <status> is not JSON", carrying the request id); it used to resolve `undefined`. An abort while the body is read rethrows the abort.
- The typed client fills an `:id` path param from a `*Id` field only when exactly one such field exists; with two, the param stays empty and the request is refused instead of taking whichever key came first.
- `@civfix/shared` builds with tsup code splitting, so the entry points share one module instance: an `AppError` thrown by `@civfix/shared/client` is `instanceof` the root `AppError`, and a bundle carries one copy of the schemas.
- `buildIcs` emits `URL` only when `isSafeHttpsUrl` accepts it (https, no whitespace or control characters, at most 2048 chars, no userinfo, IP literal, punycode or non-ASCII host), so some URLs it used to emit are now left out. `URL` and the `ORGANIZER` mailto are written without TEXT backslash escaping (RFC 5545 3.3.3, 3.3.13), so a `,` or `;` in them is no longer corrupted; an organizer email with a control character is left out.
- `inspectBroadcastLinks` flags a `javascript:`, `data:`, `vbscript:`, `file:`, `blob:`, `jar:` or `about:` scheme only where it starts a token and runs straight into its payload, so prose such as "Questions about: parking" and URL paths such as `/data:foo` are no longer reported as `insecure_scheme`.
- `parseFeedScoreCursor` returns the post id lowercased, so a cursor with uppercase hex resolves to the canonical id.
- `parseMarkdownSubset` drops the continuation lines of a list item it dropped past the item cap, instead of appending them to the last kept item.
- `relativeAgo` renders `""` for an infinite or out-of-range epoch and for a non-finite `now`, instead of "now" or an Invalid Date.
- `contrastRatio` and `relativeLuminance` (`@civfix/shared/chip-contrast`) throw `RangeError` for a partly-hex colour such as `#12345z`, which they used to read by its valid prefix.
- The datetime helpers reuse their `Intl.DateTimeFormat`s from caches bounded to 64 entries (least recently used goes first). A formatter for the host's default locale or zone (either argument omitted) is built fresh on every call, so a device locale or time zone change shows up at once. `safeDateFormat` and `formatCount` fall back to `en-US` for a malformed locale tag.
- Fakes: `FakeChatService` takes an optional clock (`new FakeChatService(now)`) for `createdAt`; the host dashboard fake derives each event's `myCapabilities` from `hostCapabilities` for its role instead of a hand list; `FakeInboundMail` no longer trusts an `x-thread-token` header, scans the `To` and `Cc` addresses, and matches the reply domain and token case-insensitively, like the real adapter.

**Internal (no API change).** The endpoint registry is one file per domain under `src/client/endpoints/`, composed in `endpoints.ts`; every entry, path, method and flag is identical and only the key order of `Object.keys(endpoints)` changed. Fields two schema files share live in an unexported module. Design token rows alias their colour ramps with identical values. `fakes/hmac.ts` (never on an entry point) is deleted.

**Adoption.** civfix-backend `services/api` and `services/media-worker` and civfix-admin `apps/admin` move to `^0.58.0`; none imports a removed name. The new optional fields sit on `.strict()` schemas: clients adopt a new response field before the backend emits it, and the backend accepts a new request field before any client sends it (`excludeOrgId` is on a non-strict query and works in either order). civfix-govt-web stays on `^0.24.2` for tokens only, by the open decision in CLAUDE.md §4.2.
